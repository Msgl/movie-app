## Technologies Used

**OMDB API** – Source for movie data such as titles, posters, and ratings.

**Next.js** – React framework for server-side rendering and fast static sites.

**TypeScript** – Adds static typing for safer, more maintainable code.

**Tailwind CSS** – Utility-first CSS framework for fast and responsive UI design.

**Framer Motion** – Animation library to add smooth, natural transitions.

**React Icons** – Popular icon packs for React components.

**Google Fonts** – Custom web fonts for improved typography.
